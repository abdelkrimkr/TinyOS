# Palette's Journal

## 2024-10-24 - Exit Instructions in Headless Environments
**Learning:** In headless environments (like serial console only), users often feel trapped in the emulator. Providing explicit exit instructions (e.g., "Press Ctrl+A, then X") significantly improves the developer experience and reduces frustration.
**Action:** Always verify if the environment is headless and append clear exit instructions to the final system state message.
